Settings and printer

Printer connection

A browser alone cannot see the printers on a computer. The free QZ Tray helper (qz.io/download) fixes that: install it on this computer, keep it running, then press Find printers. The booth lists every printer, you pick one, and photos print at 4x6 in with no pop-up. The first time, QZ asks to allow this website: tick Remember and press Allow.

No helper? Use the launcher instead

  1. Plug in the photo printer and install its driver.
  2. Make it the default printer. Windows: Settings, Bluetooth and devices, Printers and scanners, pick the printer, Set as default.
  3. Set its paper size to 4 x 6 in (also called 10 x 15 cm or 4R), borderless if it offers it: Printing preferences.
  4. Press Download launcher below and double-click the file. It opens this booth full screen and prints silently.
  5. Press Test print and check the sheet. The border should touch all four edges.
Without the launcher the booth still works: the normal print window opens each time, and you choose the printer and 4x6 paper in it.
